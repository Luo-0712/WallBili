## 显示后端早期原型

此程序单独运行，输入短本地视频。它只在既有 Explorer 壁纸 WorkerW 下创建自己的子 HWND；不向 Progman 发送创建/重排桌面结构的消息，不修改其他窗口的父子/层叠关系，不修改 Wallpaper Engine 设置。找不到这种候选宿主时返回退出码 3，应记录“不适用”，随后调整阶段三显示后端。

可用 FFmpeg 生成约 30 秒测试视频，然后运行：

```powershell
ffmpeg -f lavfi -i "testsrc2=size=640x360:rate=30" -t 30 -c:v libx264 -pix_fmt yuv420p sample.mp4
dotnet run --project tools/WallBili.DesktopProbe -c Release -- sample.mp4 30
```

原型只覆盖主屏候选宿主，默认静音，30 秒后自动清理，Ctrl+C 可提前退出；不处理完整显示变化或 Explorer 恢复。
