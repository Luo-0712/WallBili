# WallBili

WallBili 是一款面向 Windows 10/11 的 B 站视频壁纸播放器。它可以将公开视频、分 P 视频、合集或系列整理成内容目录和播放队列，并作为桌面视频连续播放。

## 技术栈

- C# / .NET 10
- WPF
- SQLite
- mpv

## 主要功能

- 通过 B 站视频链接或 BV 号导入视频
- 自动导入视频的全部分 P
- 通过链接或 UP 主 ID、合集 ID 导入合集与系列
- 按来源浏览、刷新和管理内容目录
- 自由添加、排序和移除播放队列中的内容
- 支持顺序播放、列表循环、上一项、下一项、暂停、继续、停止和进度跳转
- 支持音量调节和播放地址重新加载
- 将视频嵌入 Windows 桌面，并选择目标显示器
- 提供“填充（裁切）”和“适应（留边）”两种画面模式
- 支持隐藏或重新显示桌面画面，并可选择在隐藏画面时继续播放声音
- 支持系统托盘控制和登录后自动启动
- 自动保存目录、队列、播放模式、音量和播放进度
- 在应用重启、系统休眠或临时网络异常后恢复播放状态

## 运行要求

- Windows 10 或 Windows 11（x64）
- mpv 0.41.0
- 使用框架依赖版安装包时，需要安装 .NET 10 Desktop Runtime
- 能够正常访问 B 站及视频 CDN 的网络环境

> WallBili 不随安装包分发 mpv。请从可信来源单独安装 mpv，并保留 `mpv.exe` 的完整路径。

## 安装

1. 获取 WallBili 的 Windows x64 发布包并完整解压。
2. 如果使用框架依赖版，请先安装 .NET 10 Desktop Runtime；自包含版不需要单独安装 .NET 运行时。
3. 单独安装 mpv。
4. 运行解压目录中的 `app/WallBili.Desktop.exe`。
5. 首次启动时，在“mpv 路径”中填写 `mpv.exe` 的完整路径。

也可以提前将 mpv 加入系统 `PATH`，或通过 `MPV_PATH` 环境变量指定 `mpv.exe`。

## 快速上手

### 1. 导入内容

在“视频链接 / BV”中填写 B 站视频链接或 BV 号，然后点击“添加视频”。如果视频包含多个分 P，WallBili 会将它们一起导入。

导入合集或系列时，可以使用以下任一种方式：

- 在“合集 / 系列链接”中粘贴对应的 B 站链接
- 填写 UP 主 ID、合集 ID，并选择“合集”或“系列”

### 2. 创建播放队列

在“视频目录”中选择一个或多个条目，点击“加入队列”；也可以点击“全部加入”。队列中的内容可以上移、下移或移除。

双击队列条目，或者选中后点击“播放所选”，即可开始播放。

### 3. 设置桌面视频

1. 勾选“桌面视频”。
2. 选择目标显示器。
3. 选择“填充（裁切）”或“适应（留边）”。
4. 点击“应用桌面设置”。

如果暂时不想显示桌面画面，可以通过主窗口或托盘菜单隐藏画面。勾选“隐藏画面时继续音乐”后，隐藏画面不会停止声音。

### 4. 使用托盘和自动启动

关闭主窗口时，WallBili 会收起到系统托盘，而不是直接退出。托盘菜单可以控制播放、切换下一项、显示或隐藏画面，以及重新打开主窗口。

需要彻底关闭程序时，请在主窗口或托盘菜单中选择“退出”。勾选“登录后在托盘启动并恢复”并应用后，WallBili 会在当前 Windows 用户登录时自动启动。

## 本地数据

WallBili 的目录、队列、播放进度和设置保存在：

```text
%LOCALAPPDATA%\WallBili
```

移动程序目录前，建议先取消登录后自动启动，再从新位置重新启用。

如需彻底卸载：

1. 取消“登录后在托盘启动并恢复”。
2. 从托盘菜单退出 WallBili。
3. 删除 WallBili 程序目录。
4. 如果不需要保留目录、队列和播放进度，再删除 `%LOCALAPPDATA%\WallBili`。

## 使用限制

- 当前支持公开且允许匿名访问的 B 站内容。
- 暂不支持账户登录、会员专享内容及其他需要登录鉴权的内容。
- 视频采用在线播放方式，WallBili 不提供视频下载或离线缓存功能。
- 当前一次只能选择一块显示器承载桌面视频。
- 视频能否正常解析和播放会受到内容状态、地区限制、网络环境及 B 站接口变化的影响。
- WallBili 不会替换或修改 Wallpaper Engine 的配置；同时使用其他动态壁纸软件时，桌面显示效果可能受其窗口层级影响。
